# Manifest ERP demo

The live demo of Manifest ERP, a supply planning ERP for a fictional electronics distributor
(Nordale Electronics). This repository holds only the compiled website and a sample-data snapshot;
the application source code is private.

**Open the demo:** https://suyashgb11.github.io/Manifest-ERP-demo/

Changes you make in the demo (creating or moving POs) stay in your browser tab.
